# VELA

**Сайт:** https://vela-homes-tau.vercel.app · **Панель:** https://vela-homes-tau.vercel.app/admin · **Репозиторий:** https://github.com/1amacio1/vela-homes

Русскоязычный сайт строительной компании: 12 проектов, фотогалереи, 5 направлений услуг, калькулятор, форма с загрузкой файлов, защищённая панель заявок и аналитики, реферальные ссылки и экспорт XLSX.

## Стек

Next.js 16 / React 19 / TypeScript, Supabase Postgres и приватный Storage, Vercel. Серверные маршруты используют service role; он никогда не передаётся в браузер. Все таблицы приложения имеют префикс `vela_`, включён RLS, доступ anon/authenticated отозван. Excel создаётся на сервере через ExcelJS.

## Запуск

```sh
npm ci
cp .env.example .env.local
npm run admin:password
npm run dev
```

Заполните окружение, выполните SQL из `supabase/migrations/` по порядку в своём Supabase. Укажите URL проекта и service role, сгенерированные hash пароля и SESSION_SECRET. Сырой пароль не хранится в репозитории. Production: `npm run build && npm start` либо Vercel.

## Окружение

| Переменная                      | Назначение                                     |
| ------------------------------- | ---------------------------------------------- |
| `SUPABASE_URL`                  | URL Supabase                                   |
| `SUPABASE_SERVICE_ROLE_KEY`     | Серверный секрет Supabase                      |
| `ADMIN_EMAIL`                   | Логин администратора                           |
| `ADMIN_PASSWORD_HASH`           | `salt:hash`, scrypt с 64-байтовым ключом       |
| `SESSION_SECRET`                | Секрет подписи сессий / upload receipts        |
| `NEXT_PUBLIC_SITE_URL`          | Канонический публичный URL                     |
| `TELEGRAM_BOT_TOKEN`            | Токен бота, созданного в @BotFather            |
| `TELEGRAM_CHAT_ID`              | ID менеджера/чата, которому разрешена отправка |
| `NEXT_PUBLIC_YANDEX_METRIKA_ID` | Номер счётчика Метрики, только цифры           |

После изменения окружения выполните redeploy. `NEXT_PUBLIC_*` встраиваются при сборке. Персональный менеджер должен сначала нажать «Старт» в боте; для группы добавьте бота и разрешите писать сообщения.

## Поведение

- Заявка сохраняется в Postgres до попытки Telegram-доставки. `after()` выполняет отправку после ответа. В панели видны статусы `pending / sending / sent / failed / not_configured`; неотправленное можно повторно отправить кнопкой. Без токена данные продолжают сохраняться. При обрыве процесса в состоянии `sending` администратор БД может проверить фактическую доставку и вернуть статус `failed` для повтора.
- Telegram содержит контакты, услуги, все параметры расчёта, UTM, реферал и сведения о файлах с приватными ссылками на 24 часа. Токен не передаётся клиенту. Уведомления без настроенного бота не имитируются.
- До 5 PDF/JPEG/PNG/WEBP/GIF/HEIC/HEIF по 10 МБ. Сервер выдаёт подписанные адреса загрузки в приватный bucket; браузер отправляет файл непосредственно в Storage. Это обходит лимит размера тела Vercel. До сохранения заявки сервер проверяет подпись списка файлов и размеры загруженных объектов. Скачать файл можно через авторизованный маршрут с 60-секундной ссылкой.
- У входа, загрузок, заявок и событий есть атомарное ограничение частоты на стороне БД; IP хранится только в виде HMAC. Авторизация — подписанный HttpOnly/Secure/SameSite cookie на 12 часов. POST проверяет Origin. Для смены пароля обновите hash и SESSION_SECRET, чтобы отозвать старые сессии.
- Собственная аналитика и Метрика включаются после согласия на аналитику. Формы и реферальная атрибуция работают и при отказе. Авторизованный администратор не увеличивает счётчики. Сессия заканчивается после 30 минут бездействия. Уникальный посетитель — случайный идентификатор браузера.
- Периоды рассчитаны по Москве. Метрики: сессии, посетители, заявки, конверсия сессий, телефон/email/CTA/калькулятор. Недельная сводка всегда за последние 7 дней. Когорты — неделя первого визита, возврат W0–W4 и число уникальных обратившихся, за последние 8 недель.
- Источник: реферальная ссылка, затем `utm_source`, внешний referrer, прямой переход. Реферальная cookie живёт 30 дней и сохраняет последнюю ссылку. URL содержит случайный 7-символьный код.
- Экспорт отдаёт все заявки, независимо от выбранного периода, со всеми полями, JSON калькулятора, вложений и UTM. Данные пользователя записываются как текст, не как формулы Excel. Приватные файлы не помещаются внутрь XLSX; сохраняются имена, типы, размеры и storage paths.
- Калькулятор: базовая ставка × площадь, + дизайн 3000 ₽/м², + ландшафтный проект 150000 ₽, + газон 800 ₽/м². Другие материалы, третий этаж, деревья, терраса, беседка и освещение отмечаются как требующие индивидуального расчёта. Нет вымышленных коэффициентов, скрытых за точной ценой.

## Проверки

```sh
npm run typecheck
npm run build
npx playwright install chromium
npm test
```

Для интеграционных проверок нужен работающий сайт и `TEST_BASE_URL`, `TEST_ADMIN_EMAIL`, `TEST_ADMIN_PASSWORD`. Тест создаёт явно обозначенные тестовые данные; не используйте реальные персональные сведения.

## Демонстрационное содержимое

Проекты, характеристики, отзывы, контакты вымышлены по ТЗ. Галереи содержат референсы разных объектов. Источники и лицензии фото — `PHOTO_CREDITS.json` и `/credits`. Цены предварительные. До реального запуска замените демонстрационные контакты, добавьте реквизиты оператора и актуальные условия обработки персональных данных. Заявки хранятся в выбранном проекте Supabase в регионе eu-central-1; оцените требования к размещению реальных данных до коммерческого использования.

## Обслуживание

Делайте резервные копии БД и Storage в настройках Supabase. Удаление заявки и её файлов выполняется владельцем в Supabase; CRM и автоматические рассылки намеренно не добавлены. Незавершённые загрузки могут оставлять приватные файлы без заявки: периодически удаляйте старые неподвязанные папки в `vela-attachments`. Деплой не создаёт платных ресурсов автоматически.
